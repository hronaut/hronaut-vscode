# Changelog

## 3.12.2

- New Marketplace description and README: "Give your coding agent its own browser. Keep yours." Hronaut is a visible desktop browser for coding agents, with a separate workspace for each project. The extension itself is unchanged.

## 3.12.1

- The extension is now open source under the MIT License. Hronaut itself, the app the extension connects to, keeps its Subscription and Trial License.

## 3.12.0

- First release in the VS Code Marketplace and Open VSX. The extension adds Hronaut's MCP server to the editor, so agents such as GitHub Copilot's agent mode can use Hronaut without an `mcp.json` entry, and sends Hronaut's owner token when the editor starts the server.
